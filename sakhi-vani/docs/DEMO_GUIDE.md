# Demo guide (about 8 minutes)

Tip: in stand-alone mode both accounts share one browser store. To switch users: Settings/More → Log out → choose the other entry card. Reset any time with Settings → *Reset demo data*.

## Flow A — ASHA worker (voice documentation)
1. Open SAKHI VANI → choose a language → **ASHA Worker**.
2. **Use demo account** → Log in (Meera).
3. Dashboard: point out synthetic stats (25 households, 48 beneficiaries, today's visits, overdue, records needing updates, missing documents).
4. Search **SYN-001** (or "Lakshmi") → open profile. Show DEMO DATA badge, consent status, missing information (EDD), follow-ups, documents.
5. **Open Beneficiary Records** → Village Register → ASHA Diary → Maternal Health Record. Show provenance badges and "Not measured" for BP.
6. Back → **Speak About Today's Visit**. Tap the mic (Chrome) or **Use demo transcription** (labelled SIMULATED).
7. **Process transcript** → review screen: original transcript, extracted fields per record with evidence and confidence, "confirm" fields unticked, **Additional information required** (BP not provided, ANC details, follow-up date needs confirmation, EDD).
8. Edit a field, tick the suggested follow-up date, optionally add EDD manually.
9. Tick the confirmation → **Approve and save** → success: fields saved, today's visit completed, follow-up created.
10. **View notifications** → "Follow-up scheduled: Lakshmi (SYN-001)". Open records to show "Voice, reviewed" badges.

## Flow B — Citizen, schemes and ASHA assistance
1. Log out → **Citizen** → demo account (Lakshmi).
2. Home: greeting, beneficiary ID, next appointment, "Government Health Schemes Available for You".
3. **My Health Profile**: records with provenance and "what you share, and with whom".
4. **Schemes** tab → note "needs verification" notice and central vs Karnataka badges → open **PMSMA** or **PMMVY** → details, documents, process, official link, source.
5. **Check my eligibility** → profile details are pre-used → answer one question at a time (e.g. Yes / Not sure).
6. Results: Potentially eligible / More information required / Criteria not currently met, with criteria ✓ ✗ ?, still-needed info, documents and application steps.
7. **Get ASHA help** → tick consent → Continue → confirm **Yes, send**.
8. Log out → Meera → pop-up/alert "New assistance request" → More → Assistance requests → **Update status** → ASSIGNED / IN PROGRESS.
9. Log out → Lakshmi → notification about the status → Profile → My assistance requests shows the progress.

## Flow C — Telephone calling assistant (simulated)
1. As Lakshmi → **Call SAKHI VANI** → note **DEMO CALL SIMULATOR**, no phone number shown.
2. Choose English / हिंदी / ಕನ್ನಡ → **Start simulated call**. Greeting is read aloud if the device has a voice for that language.
3. Tap "I am pregnant. Are there any government schemes for me?" → answer: Karnataka, 25, 7, and Yes/No/Not sure chips (or speak/type).
4. Assistant explains results + missing information and offers ASHA help → **Yes**.
5. "Request created… Reference REQ-…" → **That is all** → call summary (topics, schemes checked, request id, transcript deleted per retention setting).
6. Log in as Meera → new request "Call assistant follow-up" with *via call assistant*.

## Extra talking points
- Newborn (SYN-003) shows HBNC record; child (SYN-004) Immunisation + overdue visit; postnatal (SYN-002); elderly (SYN-005).
- Area restriction: SYN-901 is outside Meera's area and cannot be opened (403, logged).
- Ask the assistant "Is it safe to stop my tablets?" (medicine guardrail) or "there is heavy bleeding" (urgent guidance, call 108).
